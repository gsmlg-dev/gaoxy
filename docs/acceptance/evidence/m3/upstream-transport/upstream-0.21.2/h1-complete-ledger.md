## Lawful traces and exact N8 stopping point

These finite traces refute a proposed release implication. None proves arbitrary-repeat growth or a leak. Same-sender signal order may bound part of a logical monitor queue; the missing theorem must also cover native pre-enqueue state, scheduler cancellation queues, refcounts and deferred thread-progress cleanup. Acknowledgement from another sender is not a blanket drain.

### T1: cancel_timer(false)/removed logical entry => expiry consumed and native timer/message reclaimed

1. Timer executor CAS ACTIVE->TIMED_OUT.
2. Executor pauses before erts_alloc_message/erts_queue_message.
3. Pool removes entry and cancel_timer sees non-ACTIVE; false is allowed.
4. Timer executor later enqueues {:expire,token}.

Sources: `timer:1089-1147`, `timer:1810-1888`, `pool:104-118,202-212`. Missing: N8 selected executor/profile and bounded pre-enqueue+queue+canceled cleanup overlap.

### T2: ACK + demonitor flush => every native monitor/buffer object globally reclaimed

1. chunk caller monitors stream and sends current chunk.
2. Stream delivers; reader/send credit eventually yields ACK.
3. Caller receives ACK and demonitor[:flush], then is permitted another chunk.
4. Native demonitor is separately routed; deinstalled signal arrays can wait thread progress/refcount zero.

Sources: `stream:84-114,214-228`, `signal:2930-2968`, `signal:10581-10660`, `signalh:1957-1977`. Missing: N8 complete same-sender logical-order theorem plus native/refcount/thread-progress overlap ceiling; ACK ordering may bound target signals, not established arbitrary-repeat leak.

### T3: timeout alias deactivation or a different-sender later reply => all old calls/native work consumed

1. Caller sends finite GenServer.call request with alias monitor.
2. Caller timeout deactivates alias/demonitors; target can still have queued request.
3. Another sender completes a later call to another target or the same target.

Sources: `gen:251-280`, `life:386-395`, `pool:16-31`. Missing: N8 each edge sender/target/order and deferred reclamation; canceled reply is not target request removal.

### T4: public completion :ok => tracker/native metadata already reclaimed

1. Tracker writes atomics latch2.
2. Completion waiter observes2 and returns :ok.
3. Tracker then returns stop and native exit/monitor processing follows.

Sources: `life:358-363`, `completion:116-143`. Missing: Q3 local helper/root termination plus N8 frontier.

### T5: mailbox snapshot/zero logical resource count => controls consumed or old allocations reclaimed

1. Pool calls Process.info(self(),:messages), obtaining a copied list.
2. The original messages remain in its mailbox; aggregate scope resource count can separately be zero.

Sources: `pool:186-188`, `scope:56-86`. Missing: N1 copied snapshot roots + N8 certified mailbox/control frontier.

The concrete native bodies show `bif_timer_timeout` ACTIVE→TIMED_OUT before message allocation/enqueue; `access_btm` can return a non-active result without consuming that message. Cross-scheduler cancellation uses `queue_canceled_timer`; `handle_canceled_queue` observes thread-progress boundaries and an operation limit; exit cleanup can yield.
