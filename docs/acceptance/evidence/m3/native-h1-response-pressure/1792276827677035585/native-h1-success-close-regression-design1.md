## Pitfalls and scope

- Suspending guardian alone is insufficient: already-forwarded end might be queued. Draining before suspension is insufficient: a later end can race. Same-sender fence plus suspension covers both without assumed ACK ordering.
- Restoring a held end before the positive post-chunk waiting phase removes the reproducer. Send only captured original tuples, never synthetic `{:end,[]}`.
- Keep the actual socket and native response implementation; a fake closed result or Exchange transport wrapper left installed would test different semantics.
- Tuple fixed0 is not generally wire complete: H2/H3 still owe END_STREAM. This regression is native H1 only. Incomplete fixed/native chunked cancellation controls can follow as separate tests; preserve existing protocol gates.
- Any unexpected guardian error, duplicate end, deadline expiry, missing EOF or unjoined actor invalidates the test setup/result. Do not label those expected RED.
