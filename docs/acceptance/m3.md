## Resource and unsupported-profile boundaries

Native H2 uses fixed 16 KiB TI active-once socket buffers, `:inet`, and TLS
internal-active-n 1..100. Decoder, parser carry, qualified SSL delivery/copy
allowances and bounded control records are reserved before codec work;
stream/writer/upstream reservations are additive. Counters exclude total
BEAM heap/GC, OTP/kernel socket memory and arbitrary trusted endpoint allocation.
The sustained-load profile has independent sampled RSS/process/mailbox ceilings;
sampling cannot establish an unsampled peak bound.

Supported downstream H2 does not imply upstream H2/reuse. Unsupported in this
slice: h2c HTTP/1 upgrade, H2 CONNECT/WebSocket extended CONNECT/server push,
HTTP/3, TLS directional half-close, interception/SNI/PROXY/SOCKS, UDP
broadcast/multicast relay and external JSON for embedded group/forward/relay
APIs. Existing ordinary core multicast hosting retains its own historical
qualification. Standalone JSON resolves only `static` and fixed `reverse_proxy`
route targets and exposes a local reload API, without a management listener.
