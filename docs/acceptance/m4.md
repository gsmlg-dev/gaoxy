## Limits and excluded operations

Initial server profile is concrete IPv4, QUIC v1, ALPN `h3`, local fixture
credentials and 1-RTT. Dynamic QPACK, server push, H3 WebSocket, WebTransport,
DATAGRAM, extended CONNECT, 0-RTT, resumption, migration, mTLS, wildcard and IPv6
are unsupported. Ordinary CONNECT returns 501. Transport admission receipts
do not establish peer delivery. Host shutdown proves bounded local cleanup,
not a graceful GOAWAY drain.

restricted. The release-artifact E2E workflow remains disabled. Hosted CI,
release/publication and production acceptance are NOT RUN for this work.
