# Gaoxy v0.5.2

This patch releases the existing Gaoxy runtime from its new repository,
[gsmlg-dev/gaoxy](https://github.com/gsmlg-dev/gaoxy), and retries public Hex
distribution after the previous organization's hosted release could not start.
Runtime code and locked dependencies are unchanged from v0.5.1.

The five MIT distributions are `gaoxy`, `gaoxy_http`, `gaoxy_http3`,
`gaoxy_proxy` and `gaoxy_websock_adapter`, all version 0.5.2. The adapter retains
the OTP application name `websock_adapter` and upstream WebSockAdapter 0.6.0
source attribution and license. Phoenix dependencies:

```elixir
{:gaoxy_http, "~> 0.5.2"},
{:websock_adapter, "~> 0.5.2", hex: :gaoxy_websock_adapter, override: true}
```

Configure the endpoint with `adapter: Gaoxy.PhoenixAdapter` and the existing
HTTP/HTTPS and explicit WebSocket-path settings. The override preserves Gaoxy's
WebSocket dispatch and native H2/H3 handshake validation. See the
[HTTP guide](https://github.com/gsmlg-dev/gaoxy/blob/v0.5.2/docs/native-http.md).

All five packages are published on public Hex. The release workflow built
them before publication, published them in dependency order, and verified
public tarball bytes before tagging. GitHub assets contain those five source
packages, the Linux x86_64 application archive and `SHA256SUMS`. Independent
downloads verified all seven asset digests and all six checksum entries. The
[release acceptance](https://github.com/gsmlg-dev/gaoxy/blob/main/docs/acceptance/release-0.5.2.md)
records actual hosted, Hex, consumer and download results separately.

All seven packaging regressions passed. Clean consumers resolved the published
packages from public Hex and passed the original core 1, HTTP 2 and Phoenix 4
tests, with strict compilation and no failures.

There are no new protocol capabilities. Existing activation differences and
protocol limits remain unchanged. This patch adds no Debian portability or
production-deployment claim. Specialist abnormal/disconnect, slow-peer,
pressure, load and soak qualification and release-artifact E2E remain outside
this release.
