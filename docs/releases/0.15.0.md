# Gaoxy 0.15.0

Gaoxy upgrades its HTTP, TLS, QUIC and transport dependencies to the coordinated
Hex `1.0.0-rc.4` releases: `http_fetch`, `http_web_socket`, `http_core`,
`http_runtime`, `elixir_quic`, `elixir_quic_http3`, `ex_ssl`, `abyss` and `hell`.
Hell now resolves directly from Hex. Application, example and consumer locks
and package metadata are synchronized with these releases.

Proxy HTTPS and secure WebSocket clients use the supported ExSSL backend.
Managed HTTP/2 response validation accepts the new response-stream idle-timeout
field only when disabled, retaining strict response-shape and size checks.
Dedicated HTTP/1 proxy receive accounting covers ExSSL's 1 MiB plaintext
delivery bound, with matching resource reservations and framing limits.

Regression coverage checks the updated client options, response validation,
TLS trust and hostname rejection, and maximum plaintext delivery boundaries.
