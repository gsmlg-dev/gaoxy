# Gaoxy 0.10.0

Gaoxy.Test adds independently consumable HTTP test fixtures with atomic request
expectations, ordinary Plug handlers, bounded journals and automatic per-test
ExUnit verification. Install `{:gaoxy_test, "~> 0.10.0", only: :test}`. Manual
mode works without starting ExUnit.

Profiles cover H1, trusted HTTPS, h2c and TLS H2, plus optional H3 with an explicit
aligned `gaoxy_http3` dependency. Finite streaming/SSE, established persistent SSE
and H1 WebSocket helpers expose event-driven observations. Extended-CONNECT
WebSockets and Bypass-style down/up are outside this helper's scope.

Callback assertions retain their original stacktraces. Verification survives the
ExUnit teardown boundary; bounded finalization records pending callbacks, session
failures and cleanup uncertainty. A narrow core ownership repair retains handlers
created during listener suspension so a pending TLS handshake cannot escape
forced cleanup.

The ordinary consumer excludes H3/QUIC/ExSSL, proxy and client dependencies. Test
infrastructure stays outside production releases. Isolated extracted-tarball
consumers cover ordinary use, explicit H3, and published HTTPFetch 0.21.14. The
release workflow includes all six aligned Hex distributions and a fresh Hex-only
consumer after publication.

The integrated source preserves 0.9.0's Phoenix migration, stream lifetime,
WebSocket limits and client-certificate work. Raw negative peers and independent
interoperability suites remain intact. Specialist pressure/soak qualification and
deployment remain outside this release.

See the [package guide](../../apps/gaoxy_test/README.md),
