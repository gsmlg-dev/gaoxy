# Gaoxy 0.16.4

- Proxy: an upstream transport, its custodian or an upstream group that enters a
  fail-closed state now emits `[:gaoxy, :upstream_quarantined]` with
  `component` and `reason` metadata and logs a warning. These states clear only
  on a route reload or gateway restart and were silent before. See
  [quarantined upstream resources](../gateway.md#quarantined-upstream-resources).
- UDP relay: new optional limit `max_source_associations` caps the associations
  one source address may hold, so one host cannot occupy every slot. It defaults
  to 256, the global ceiling, which leaves existing behaviour unchanged.
  Rejections use the reason `:source_association_limit`.
- Proxy: when a client sends no `User-Agent`, the dedicated HTTP/1.1 upstream
  path sends `user-agent: gaoxy` instead of the HTTP Fetch default, which named
  the host's OTP, Elixir and client versions. This is temporary until
  [http_fetch#171](https://github.com/gsmlg-dev/http_fetch/issues/171).
- CI: workflow actions are pinned to commit SHAs.

One new optional configuration key; no dependency changes.
