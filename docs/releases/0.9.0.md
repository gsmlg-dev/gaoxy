# Gaoxy 0.9.0

Long-lived SSE responses can explicitly opt out of the ordinary absolute
request deadline. Select `http_limits.stream_timeout: :infinity` on a listener
or `Gaoxy.HTTP.put_stream_timeout(conn, :infinity)` for a route before starting
its chunked response. The default remains `:request`; positive finite stream
lifetimes are also supported. HTTP/1 and HTTP/2 retain finite header, body-read
and individual-write deadlines, admission accounting, cancellation and bounded
shutdown. HTTP/2 streaming remains local to its stream. HTTP/3 does not support
the opt-in. See [streaming responses](https://github.com/gsmlg-dev/gaoxy/blob/v0.9.0/docs/streaming-responses.md).
Fixes [#3](https://github.com/gsmlg-dev/gaoxy/issues/3) and
[#7](https://github.com/gsmlg-dev/gaoxy/issues/7).

OTP TLS and Phoenix HTTPS listeners accept `verify`, `cacertfile`, and
`fail_if_no_peer_cert`. An enrollment listener can allow clients without a
certificate while verifying any certificate supplied; a required-certificate
listener rejects absence. Trusted DER peer certificates reach HTTP and Phoenix
WebSocket peer data, and forwarded HTTP headers cannot supply TLS identity.
Invalid verification combinations fail explicitly. See
[client certificates](https://github.com/gsmlg-dev/gaoxy/blob/v0.9.0/docs/client-certificates.md).
Fixes [#5](https://github.com/gsmlg-dev/gaoxy/issues/5).

WebSocket message capacity now follows the selected `max_frame_size` when
`max_message_size` is omitted. Phoenix's accepted frame-size option therefore
supports messages above 256 KiB. Explicit direct-WebSock message limits,
aggregate fragmented-message limits, and the service admission budget remain
authoritative. See [WebSocket limits](https://github.com/gsmlg-dev/gaoxy/blob/v0.9.0/docs/websocket-limits.md).
Fixes [#6](https://github.com/gsmlg-dev/gaoxy/issues/6) and
[#9](https://github.com/gsmlg-dev/gaoxy/issues/9).

Phoenix-owned WebSocket options `log` and `code_reloader` are accepted after
Phoenix applies their policies. Wire-engine settings retain strict validation.
Fixes [#8](https://github.com/gsmlg-dev/gaoxy/issues/8).

The HTTP supervision child preserves the validated instance shutdown budget,
including configured drain time and cleanup headroom.
Fixes [#10](https://github.com/gsmlg-dev/gaoxy/issues/10).

The five Hex distributions and standalone application use coordinated 0.9.0
metadata. Existing dependency pins and vendored adapter source provenance are
retained. The [acceptance record](https://github.com/gsmlg-dev/gaoxy/blob/v0.9.0/docs/acceptance/release-0.9.0.md)
separates implementation tests, release qualification and publication evidence.
