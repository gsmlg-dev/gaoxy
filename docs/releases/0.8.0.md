# Gaoxy 0.8.0

One Phoenix Endpoint can now own HTTP/1.1, HTTP/2 and optional HTTP/3 through
`Gaoxy.PhoenixAdapter`. Configure explicit `http3:` credentials and binding
beside `http:` and `https:`; one ListenerSet initializes the Endpoint once and
owns one core instance. Actual transport addresses, recovery state and
capabilities are inspectable. Native H2/H3 WebSocket CONNECT keeps exact socket
paths, LiveView, Channels and development code reload.

`Gaoxy.Proxy.Gateway` embeds the managed gateway without `gaoxy_server`.
Applications declare logical listener sets, share one route generation across
their H1/H2/H3 listeners, reload with an expected accepted revision, inspect
bounded operation receipts, and stop the complete runtime. Stable stores retain
accepted routes and immutable upstream trust through runtime-owner recovery.
Different gateways can reuse logical IDs independently. Standalone JSON v1,
environment/readiness output and file-based reload delegate to the same runtime.

`Gaoxy.HTTP.ListenerSet` supplies pure declarations and optional providers.
Supported deferred core activation preserves the complete planned resource and
shutdown budgets, owns late startup/rollback and replaces private Instance
startup. Optional readiness-aware Alt-Svc discovery runs before response-header
budget checks for secure H1/H2 native, Plug and proxy final responses, including
streaming. Discovery remains disabled by default.

Existing single-service builders, HTTP defaults and mixed cleartext
H1/prior-knowledge H2 remain supported. H3 requires `gaoxy_http3`; HTTP and Proxy
do not acquire a reverse dependency. Independent port-zero bindings remain
independent. Unsupported H3 bind/TLS capabilities still fail explicitly. Reload
changes routes, not listener bindings or certificates; complete root/VM loss
returns to the host's startup configuration.

The five Hex distributions and standalone application use coordinated 0.8.0
metadata. See [Phoenix configuration](https://github.com/gsmlg-dev/gaoxy/blob/v0.8.0/docs/phoenix.md),
[embedded Gateway APIs](https://github.com/gsmlg-dev/gaoxy/blob/v0.8.0/docs/embedded-gateway.md),
[ListenerSets](https://github.com/gsmlg-dev/gaoxy/blob/v0.8.0/docs/listener-sets.md), and the
[acceptance record](https://github.com/gsmlg-dev/gaoxy/blob/v0.8.0/docs/acceptance/unified-listeners-embedded-gateway.md) for
commands, evidence, known baseline failures and publication status. Specialist
pressure/soak qualification and deployment remain outside this release.
