# Gaoxy 0.6.0

This minor release refreshes the published HTTP, TLS and QUIC dependency cohort
to `0.21.14`: `http_fetch`, `http_web_socket`, `http_runtime`, `http_core`,
`elixir_quic_http3`, `elixir_quic` and `ex_ssl`. The independent QUIC consumer
uses the same version. The Phoenix example now uses Phoenix `1.8.16` and
LiveView `1.2.13`.

All five Gaoxy Hex packages are versioned together as `0.6.0`, with exact
internal package requirements. Installation guides now select `~> 0.6.0`;
applications using `~> 0.5.x` must update their requirement to adopt this release.
The `gaoxy_websock_adapter` distribution retains the OTP application name
`websock_adapter` and the documented Phoenix dependency override.

Core retains Hex `abyss == 0.9.0` and Hell `0.1.2`. Ordinary services do not
install `abyss_raw`, Rustler or the former bundled DHCP NIF. OTP/ERTS and
OTP crypto/OpenSSL retain their own native components.

Gaoxy's runtime implementation is unchanged from `0.5.5`; this release adds no
new protocol capability. It includes the five Hex packages and the Linux x86_64
standalone application. See the [dependency refresh verification](../acceptance/dependency-refresh-2026-10-21.md)
and [release verification](../acceptance/release-0.6.0.md) for executed tests,
source identities and publication results.
