# Gaoxy 0.16.5

- HTTP: add `[:gaoxy, :http, :failure]` for bounded HTTP/1 and HTTP/2 header
  rejection, deadline expiry and escaped endpoint failures. Diagnostics identify
  the lifecycle stage, a finite reason, elapsed time, server-generated
  correlation and the successfully submitted response status. Prepared responses
  do not count as committed responses. Request data and exception contents are
  excluded. See [the diagnostic contract](../http-diagnostics.md).
- Preserve existing wire responses, deadline enforcement and cleanup. HTTP/2
  endpoint and request failures remain stream-local; incomplete frame/header
  blocks retain their existing connection-level protocol failure behavior.

No configuration or dependency changes. Resolves
[internal request #28](https://github.com/gsmlg-dev/gaoxy/issues/28).
