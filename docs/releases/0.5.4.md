# Gaoxy 0.5.4

Standalone managed-upstream recovery preserves the latest accepted route
configuration and reconstructs handles for the recovered runtime. Confirmed
termination of an obsolete managed owner settles its pin metadata while
independent custodians retain resource cleanup. Live-owner cleanup errors remain
visible and retryable, and the retired-generation activation guard remains.
Fixed and grouped regressions cover recovery followed by another valid reload.

Repository-owned bitstring matches explicitly pin externally bound size variables
for Elixir 1.20. Compiler-proven unreachable branches are removed without changing
the reachable lifecycle and protocol error paths. The supported Elixir/OTP matrix
and strict warnings policy are preserved.

The optional QUIC CI consumer now creates its expected Python 3.12 virtual
environment and installs the existing pinned aioquic requirements before running
the validating independent peer.

See the [acceptance record](../acceptance/standalone-ci-followup-2026-10-21.md)
for exact source, executed gates, independent review and publication evidence.
This patch adds no protocol features or deployment/production qualification.
