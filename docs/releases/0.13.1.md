# Gaoxy 0.13.1

Plug applications and middleware can set legacy connection-specific response
headers without turning HTTP/2 SSE responses into HTTP 500. The Plug adapter
removes these headers, including fields named by `Connection`, before H2/H3
response serialization. Buffered, file, streaming and informational responses
use the same compatibility policy.

Ordinary headers and payloads are preserved. HTTP/1 response behavior and strict
native response/header and framing validation remain in effect. The native
WebSocket persistence and capacity defaults introduced in 0.13.0 are unchanged.

All six Hex distributions and the standalone application use version `0.13.1`.
See the [issue 18 plan](../plans/issue-18-plug-response-headers.md) and the
[release acceptance](../acceptance/release-0.13.1.md) for verification and source
identity.
