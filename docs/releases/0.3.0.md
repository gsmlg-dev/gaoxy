# Gaoxy v0.3.0

Release candidate notes. All prescribed implementation checks and final independent
M4 acceptance PASS. Portable build, packaged runtime qualification and
publication remain pending. [Release acceptance](../acceptance/release-0.3.0.md)
records those separate gates.

v0.3.0 adds opt-in native HTTP/3 alongside H1/H2, sharing the existing
Endpoint/Exchange/Response and Plug APIs. Fixed HTTPS/H3 reverse origins use
caller-owned public Session operations and a dedicated endpoint per request,
with verified CA trust, bounded streaming, ordered request/response trailers,
deadlines and confirmed local cleanup. Standalone version1 JSON explicitly
selects H3 services and fixed H3 origins; route reload preserves in-flight
generations and rejects invalid replacements without changing the listener.

H1 remains the upstream default, with dedicated per-request connections.
Upstream H1 pools and upstream H2 are not implemented. H3 origins require
explicit protocol selection and HTTPS/CA configuration; there is no automatic
fallback, pool or request replay. Upstream groups remain dedicated H1.

The installed HTTP/QUIC cohort is0.21.4. Supported public8KiB Session
fragmentation retains the16KiB application DATA ceiling. Trusted embedded QUIC
specifications accept polling1..1000ms, default10ms. The UP2 tiny-window workload
selects1ms and passes within its original5s deadline; it does not qualify
default10ms burst throughput. The data-only schema retains its existing default.
Fetch H3 cleanup completion remains unsupported and separate from Session
lifecycle evidence.

Local implementation verification includes530 scoped tests/0 failures, strict
umbrella/Phoenix builds, native/Plug/browser gates47/59/19, standalone16,
Session50 (17network+2policy+31boundary doubles) and clean consumers1/2/2.
The complete upstream matrix passes66network+2policy in both independently
reviewed executions. [M4 acceptance](../acceptance/m4.md) records exact source
identities, workload boundaries and immutable historical failures.

The locally assembled0.3.0 release also passes core TCP/TLS/UDP, gateway H1/H2
and three packaged H3 exchanges, with normal child exits and port rebind.
Portable exported bytes and the fresh offline runtime remain separate gates.

Dynamic QPACK, push, H3 WebSocket, extended CONNECT, WebTransport, QUIC DATAGRAM,
0-RTT/resumption, migration, mTLS, IPv6/wildcard QUIC and graceful H3 GOAWAY drain
remain unsupported. Stop proves bounded local cleanup. Forward HTTP/H1 CONNECT
retains required authentication and destination policy.

The planned artifact is `gaoxy-0.3.0-linux-x86_64.tar.gz`, targeting Debian
bookworm/glibc x86_64. Fresh source/archive/lock binding, five packaged application
versions, checksums, real core/H1/H2/H3 exchanges, finite shutdown/rebind,
network-disabled runtime and all-ELF linkage inspection must pass before
publication. Other platforms remain unqualified. No artifact identity or
download URL is assigned before execution.

Hosted CI and publication remain separate from local evidence. Deployment,
production data/certificates, Vault and public management are excluded;
release-artifact E2E remains disabled. This beta makes no full-conformance,
security-audit or production-acceptance claim.

Final M4 implementation acceptance: [independent review](../acceptance/evidence/m4/upstream-matrix/review-m4-final-implementation-candidate-acceptance-1791858009332797257.json),
PASS with no unresolved findings. Portable qualification/publication stay separate.
