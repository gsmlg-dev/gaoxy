# Gaoxy 0.15.1

Fixes [#21](https://github.com/gsmlg-dev/gaoxy/issues/21): hidden cgroup mounts
in rootless Podman could leave memory observations unavailable and prevent HTTP
connection admission even though a valid memory controller remained visible.

Memory detection now resolves mount attachments before validating visible
controller roots. Finite and unlimited visible limits supply capacity and safety
observations, while covered controllers and their old descendants are excluded.
Ambiguous mount relationships, traversal in visible controller paths, and mounts
intercepting required controller files continue to fail closed.

Regression coverage includes the reported Podman layout, reordered mount IDs,
hidden and visible descendants, controller aliases, and safety headroom.
