# Gaoxy 0.16.7

- Require Plug 1.20.4 or newer for `gaoxy_http`, `gaoxy_test` and the published
  `gaoxy_websock_adapter` distribution. This excludes versions affected by
  [EEF-CVE-2026-120287](https://osv.dev/vulnerability/EEF-CVE-2026-120287), where
  multipart part and header framing was omitted from the configured length limit.
- Update the root and Phoenix fixture locks to Plug 1.20.4. Other resolved
  dependency versions and the vendored WebSockAdapter snapshot are preserved.

This is the current HTTP Core 1.0 release line. The HTTP Core 0.21 / Gaoxy 0.14
maintenance request is tracked separately in
[issue #30](https://github.com/gsmlg-dev/gaoxy/issues/30).

Security audits: the root project passes `mix hex.audit` with Plug 1.20.4.
The Phoenix fixture audit still reports three pre-existing advisories in unchanged
Phoenix/LiveView dependencies: EEF-CVE-2026-129344, EEF-CVE-2026-128361 and
EEF-CVE-2026-126334. Those fixture upgrades are outside this Plug repair.

Validation: 1091 scheduled cases passed (421 unit, 359 component, 311 protocol),
with no failures, exclusions or skips. Twelve packaging regressions and the
independent security/package review passed.
