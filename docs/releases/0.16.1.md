# Gaoxy 0.16.1

Gaoxy upgrades the HTTP/TLS/QUIC, Abyss and Hell cohort to Hex `1.0.0-rc.16` and
requires `~> 1.0.0-rc.16`.

- Managed HTTP/2 upstreams no longer replay requests inside http_fetch. With
  `http2_unprocessed_retry: false`, a request the upstream did not process (above
  a GOAWAY last-stream-id or reset with `REFUSED_STREAM`) fails as an upstream
  attempt (502) again, as before 0.16.0, instead of being re-sent on another
  connection where an unanswered replay surfaced as 504
  ([gsmlg-dev/http_fetch#167](https://github.com/gsmlg-dev/http_fetch/issues/167)).
- rc.15 fixes ex_ssl client exact-length reads that could report the terminal
  while plaintext was still buffered, and preloads the OS trust store when
  `:ex_ssl` starts so the first HTTPS request no longer spends its timeout on it.

No Gaoxy API or configuration changes.
