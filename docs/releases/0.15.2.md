# Gaoxy 0.15.2

- [#22](https://github.com/gsmlg-dev/gaoxy/issues/22): refresh the supported
  Abyss/Hell dependency constraints and lock the HTTP/TLS/QUIC cohort at
  `1.0.0-rc.9`, including the Phoenix example. Consumers can update without
  dependency overrides. No DATAGRAM or WebTransport capability is added.
- [#23](https://github.com/gsmlg-dev/gaoxy/issues/23): accept the boolean
  `hell_options: [transport_options: [ipv6_v6only: false]]` for explicit IPv6
  wildcard dual-stack TCP/TLS, HTTP/HTTPS, ListenerSet and Phoenix listeners.
  `true` enables IPv6-only operation. Existing TLS client-certificate policies
  remain unchanged; platform socket support still applies.
- [#24](https://github.com/gsmlg-dev/gaoxy/issues/24): expose validated, finite
  `limits` and `http_limits` through `Gaoxy.Test.open/1` for all supported
  profiles. Larger fixture bodies can use an explicitly sufficient service
  budget while retaining body limits, default settings, request journaling,
  ownership and verification.

Regression coverage includes real IPv4/IPv6 listener behavior and complete
multilingual request bodies. Requesting applications perform their own
downstream runtime and integration acceptance after updating.
