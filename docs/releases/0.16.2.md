# Gaoxy 0.16.2

- Admitted UDP datagrams can reply while their service drains, as documented.
  Each datagram reserves a reply allowance (`min(max_output, 65_507)` bytes) when
  admitted and charges a fitting reply within it, which the resource budget
  accepts during drain. A reservation that does not fit the byte or memory budget
  falls back to the exact input size without emitting `admission_rejected`
  telemetry or counting a budget rejection. Byte-limit and output-limit
  outcomes for replies are unchanged.
- An abrupt `Gaoxy.Registry` death no longer stops the `:gaoxy` application.
  The Registry runs under its own supervisor, and its restart waits (up to 5 s)
  for the previous Registry processes to exit instead of failing with
  `already_started`. Before, the application exit restarted the resource-budget
  ledger, which then fenced admission for the rest of the VM lifetime.
- Test fixtures for managed HTTP/2 fixed endpoints match the current HTTP limit
  and admission accounting shapes.

No configuration or dependency changes.
