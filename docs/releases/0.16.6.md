# Gaoxy 0.16.6

- HTTP/1: response headers with small slices sharing a bounded binary now start
  streaming normally instead of failing with `:response_header_limit` and HTTP
  500. For example, four 100-byte values sharing an 8700-byte parent now work
  like independent copies under the default 32768-byte header budget.
- Compact validated header and trailer slices before rendering, so retained
  output is bounded by their logical bytes. Keep field count, logical-size and
  individual backing limits, including rejection of a short slice backed by a
  genuinely oversized binary. Framed response validators and generic iodata
  rendering retain their aggregate backing limits.

No configuration or dependency changes. Resolves
[internal request #29](https://github.com/gsmlg-dev/gaoxy/issues/29).

Validation: 1091 scheduled cases passed (421 unit, 359 component, 311 protocol),
with no failures, exclusions or skips. Formatting, warnings-as-errors compilation,
test inventory and independent protocol/security review passed.
